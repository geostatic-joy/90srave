# Sound effects

Drop audio files in this folder and they show up in the **Sound effect** dropdown
next to the scratch upload button. `.mp3`, `.wav`, `.flac`, `.ogg`, `.opus`,
`.m4a` and `.aac` are picked up.

The app fetches `sfx/index.json` to know what is here — static hosting cannot
list a directory — and that file is generated by `scripts/build-sfx-index.mjs`,
which runs as part of `npm run dev` and `npm run build`. So:

- **In development, or before a build:** put files here and run `npm run dev` or
  `npm run build`. They are copied into `dist/sfx/` with everything else.
- **On an already-deployed site:** put files in the deployed `sfx/` folder and
  regenerate the index in place, no rebuild needed:

  ```bash
  node scripts/build-sfx-index.mjs /path/to/deployed/sfx
  ```

The label shown in the dropdown comes from the filename
(`needle-drop_02.wav` → "Needle drop 02"). Edit a `label` in `index.json` to
override it; regenerating the index keeps labels you have changed.
